Critical Production Rules & Edge Cases

Caution

Never Omit multi: true on Tokens

If you register multiple strategies into an InjectionToken without multi: true, Angular will silently overwrite earlier providers and only inject the last one.

Anti-Pattern

Avoid the "God Facade"

A Facade must remain cohesive to a single feature domain. If a Facade expands beyond 300 lines and mixes billing, user preferences, and analytics, break it down.

Best Practice

Don't Over-Engineer Small Rules

Never implement 4 strategy classes for a trivial two-branch boolean check (e.g. isAdmin ? 'Full' : 'Read'). Apply Strategy when there are 3+ variants or frequent additions.

Maintainability

Keep Adapters in data-access/

Place pure adapter mappers right next to HttpClient services. Never pass raw unmapped API DTOs into presentational components or UI templates.
