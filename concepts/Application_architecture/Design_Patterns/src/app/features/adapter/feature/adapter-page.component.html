Adapter Pattern in Modern Angular

Translates cryptic, snake_case external API responses into clean, strongly-typed UI domain models inside data-access/.

💡 Why is an Adapter essential? Backend teams often rename JSON fields (e.g., cust_full_name to customerName) or deliver prices in paise (cents). Without an Adapter, 20+ HTML templates bind directly to raw backend DTOs and break instantly. With an Adapter, components only bind to clean UI models; schema changes are isolated to one pure function!
