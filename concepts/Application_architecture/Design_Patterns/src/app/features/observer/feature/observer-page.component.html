Behavioral Signals & effect()

Observer Pattern in Modern Angular

One piece of state (the Subject) automatically notifies any number of subscribers (Observers) the moment its value changes.

💡 Built directly into Angular 22+: Unlike legacy frameworks where you had to manually implement subscribe(), unsubscribe(), and prevent memory leaks, Angular 22+ implements the Observer Pattern natively: signal() is the Subject, and computed(), effect(), and HTML templates are the Observers with automatic dependency tracking!

❌ Imperative Manual Event Wiring

  • Needs manual EventEmitter or EventBus wiring everywhere.
  • Forgetting subscription.unsubscribe() creates memory leaks.
  • Prone to race conditions and out-of-order execution.

✓ Angular 22+ Native Signals

  • Automatic dependency tracking during template execution.
  • Glitch-free push-pull evaluation graph.
  • Clean garbage collection without manual unsubscription chores.
