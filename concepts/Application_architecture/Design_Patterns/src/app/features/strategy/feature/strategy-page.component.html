Behavioral InjectionToken multi: true

Strategy Pattern in Modern Angular

Defines a family of interchangeable algorithms, encapsulates each into its own class, and selects them dynamically at runtime without if/else chains.

💡 Open/Closed Principle (SOLID): Code should be open for extension, but closed for modification. Using an InjectionToken<PaymentStrategy[]> with multi: true, adding a new payment gateway or export format only requires creating 1 new class and adding 1 line to the providers array. Existing tested code is untouched!

⚠️ Critical Gotcha: The Missing multi: true Trap When registering strategies under an InjectionToken, you MUST write: 
{ provide: PAYMENT_STRATEGIES, useClass: UpiPaymentStrategy, multi: true }
If you omit multi: true, Angular will silently overwrite earlier providers and only the last one will be available at runtime!
